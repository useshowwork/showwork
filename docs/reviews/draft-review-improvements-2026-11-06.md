# AI draft review improvements — 6 November 2026

The review dialog now uses a compact desktop queue and a mobile post selector, with Post copy / Strategy / Creative direction tabs. Native dialog behavior traps focus, supports Escape and restores the surrounding page scroll. Close and Escape preserve saved drafts; only the explicit discard action can delete them, after confirmation. Unsaved edits prompt before leaving a post or closing. The fixed footer offers Save changes when dirty, then Mark reviewed & next; adding a draft to the calendar does not publish or grant final client approval.

Progress counts successful confirmations in the current review session. Bulk review uses at most four concurrent requests against the existing confirmation endpoint, sends no stale text payload, preserves successful results and leaves failures in the queue. Existing permission, publishing and idempotency boundaries remain in use. Bulk review requires saved drafts with complete strategy; destructive and bulk operations are disabled while generation is running.

Opening a legacy draft no longer automatically generates or spends allowance. Missing context is labelled and can be entered manually or completed with an explicit AI action. The server validates any partial edits supplied for that explicit completion, preserves nonempty fields and retains editorial warnings. Newly generated complete briefs remain subject to the existing generation validation. This task does not bypass whole-campaign quality checks or persist partially validated batches: generation progress now describes preparation and quality checks rather than claiming drafts stream into the database.

Server refreshes merge updates to existing drafts, retain newer snapshots and do not reintroduce reviewed/deleted rows. The editor's existing field reconciliation preserves local edits. History loads only when expanded and ignores stale responses after switching posts. Status polling is nonoverlapping and fetches the draft list after generation finishes, rather than repeatedly loading all drafts every 2.5 seconds.

Validation: 39 focused checks pass for generation contracts, draft merging, safe close, no AI on open, bounded confirmations, partial failures and editor/storage responses. The unrelated historical additive-migration test was excluded because its external /private/tmp PGlite dependency is absent. TypeScript passes. Isolated browser QA used mocked drafts at 320, 393, 768 and 1440px: no horizontal overflow/out-of-bounds buttons; tabs, footer save, review progress and close-without-delete were exercised without AI requests or real content mutations. Production AI timing was not benchmarked.

No new database migration is required. Deploy the updated app code and restart as usual. The temporary browser fixture and generated preview assets live outside the repository.
